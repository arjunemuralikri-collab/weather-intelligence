# Weather Intelligence App

A Weather Intelligence application built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**. It fetches real-time weather metrics and 7-day forecasts using the public **Open-Meteo API** and provides smart lifestyle/planning recommendations.
